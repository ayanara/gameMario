# Game Mario Jump

Jogo simples de Jump usando JavaScript e HTML para iniciantes.

O jogo foi feito seguindo o tutorial do video **_Como criar um jogo SIMPLES usando JavaScript e HTML | JavaScript para iniciantes - Tutorial_**
[**Acesse ao video aqui**](https://www.youtube.com/watch?v=r9buAwVBDhA&t=600s&ab_channel=ManualdoDev) 😊

## Como executar

1. Abra a pasta do projeto no VS Code.
2. Inicie um servidor local para a pasta (por exemplo, com a extensão **Live Server**: clique com o botão direito em `index.html` e escolha **Open with Live Server**).
3. O jogo abrirá no navegador. Pressione qualquer tecla para fazer o Mario pular e desviar do cano.

Também é possível abrir `index.html` diretamente no navegador. Se as imagens não aparecerem, use um servidor local como o Live Server.
